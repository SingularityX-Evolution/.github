# 挑战方案提交邮件模板

[English](challenge-submission-template.md) ｜ [返回首页](../README.zh-CN.md) ｜ [挑战列表](../challenge-board/README.zh-CN.md)

收件人：`join@singularityx.tech`  
邮件标题：`[Challenge Submission] <挑战编号> - <姓名>`

确认题目及申请档位仍开放后，复制以下正文填写。首次提交及获准的升级提交均使用本模板。

```text
挑战编号：
提交类型：首次提交 / 获准的 S 档升级
本人真实姓名：
有效联系方式：邮箱 / 手机 / 微信（至少一种）
本人 GitHub 主页：https://github.com/<本人用户名>
提交材料：附件名称或可访问的代码仓库链接（如通过公开 PR 提交，附 PR 链接）
提交版本：commit hash 或压缩包 SHA256

本人确认材料真实，并拥有或已取得提交相关材料所需的权利。
```

**姓名、有效联系方式、本人 GitHub 个人主页完整链接为必填项。** 昵称、用户名、仓库链接或组织主页不能替代所需的本人信息；材料不完整时，补齐前不进入正式评审。

运行与复现说明、依赖环境、数据来源与授权、测试或评估报告、已知限制等统一放入提交材料，邮件无需逐项重复。具体交付要求及提交次数、升级条件见[题目](../challenge-board/README.zh-CN.md)与[贡献指南](../CONTRIBUTING.md)；补充身份与联系信息不得用于替换代码或实验结果。

私人联系信息通过邮件提供，不写入公开 PR、Issue 或代码。提交信息不代表同意对外公开，按[隐私政策](privacy-policy.zh-CN.md)处理。

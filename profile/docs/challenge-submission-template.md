# Challenge Submission Email Template

[中文版本](challenge-submission-template.zh-CN.md) | [Homepage](../README.md) | [Challenge board](../challenge-board/README.md)

To: `join@singularityx.tech`  
Subject: `[Challenge Submission] <Challenge ID> - <Name>`

Confirm that the challenge and requested grade remain open, then complete the body below. Use this template for initial submissions and authorized upgrades.

```text
Challenge ID:
Submission type: Initial submission / authorized Grade S upgrade
Your real name:
Valid contact: Email / phone / WeChat (at least one)
Your personal GitHub profile: https://github.com/<your-username>
Submission materials: Attachment name or accessible repository URL (include the PR URL if submitting through a public PR)
Submitted version: Commit hash or package SHA256

I confirm that the materials are accurate and that I own or have the necessary rights to submit them.
```

**Your real name, valid contact details and full personal GitHub profile URL are required.** Nicknames, usernames, repository URLs and organization profiles do not replace the required personal details. Incomplete submissions do not enter formal review until complete.

Include running and reproduction instructions, dependencies, data sources and permissions, tests or evaluation reports, and known limitations in the submitted materials; the email need not repeat each item. The [challenge](../challenge-board/README.md) and [contribution guide](../CONTRIBUTING.md) govern deliverables, submission limits and upgrade eligibility. Identity or contact supplements must not replace submitted code or experimental results.

Provide private contact details by email, not in public PRs, Issues or code. Submission does not authorize public disclosure; the [Privacy Policy](privacy-policy.md) applies.

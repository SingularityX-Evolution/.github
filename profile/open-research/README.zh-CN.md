# 金融研究问题征集与采纳奖励规则

**所有解释权归零界演化所有。**

零界演化面向个人、团队及机构，长期征集金融量化领域尚未解决、且提出者已经进行过思考或实际探索的问题。参与无需内部身份或邀请，不收报名费，不设统一征集截止时间。

**现阶段只接受问题提案，不征集已经解决的问题或完整解决方案。问题经平台采纳后，向提出者发放提问奖金，并将其整理为公开挑战，邀请更多参与者研究解答。**

## 一、什么样的问题可以提交

提交的问题应同时满足以下条件：

1. 属于金融量化研究，能够说明具体场景、问题范围及研究价值。
2. 提出者已经进行过具体思考或探索，能够说明考虑过哪些解释、查阅过哪些资料、尝试过哪些方法，或发现过哪些困难。
3. 核心问题仍未解决，能够明确区分已有认识、阶段性结果与尚待研究的部分。
4. 具备进一步研究的空间，经整理后可形成供外部参与者挑战的具体目标。

前期探索不以代码、实验或成功结果为必要条件。具体的推理过程、资料分析、方法比较、实践观察和失败记录均可提供；涉及资料引用、数据或实验的，应说明来源与条件。仅提出宽泛主题、未经展开的设想，或无法说明任何前期思考与探索的，应先补充材料。

已经形成完整解决方案、仅希望展示或转让成果，或申请解答、改进、独立验证奖励的，不在本阶段征集范围。已有局部结论可作为背景，但申报对象必须是确实尚未解决的具体问题，不能以已经完成的成果替代问题提案。

## 二、研究范围

第一阶段限定金融量化领域，围绕 `AI4S → RSI → AI4S` 研究路径，关注以人工智能推动研究、通过研究改进智能系统，再将改进后的系统投入新的探索。

| 方向 | 可提出的问题 |
|---|---|
| 金融机制与研究假设 | 市场现象的解释、现有方法的不足，以及如何区分不同假设 |
| 专家逻辑切片与胶囊 | 特定决策逻辑的适用条件、失效边界、标签及复用方式 |
| 多智能体与策略调度 | 协作与博弈、策略生成与竞争、组合与暂停机制中的未解问题 |
| 研究方法改进 | 实验选择、训练流程或研究流程面临的具体瓶颈 |
| 可靠性与风险控制 | 数据泄漏、回测偏差、成本约束、稳健性及 AI 攻防方面的研究疑问 |

支持使用 AI 或 Agent 辅助思考和探索，但须如实说明主要使用方式，由明确的个人或机构对材料负责。专家声望、个别成功案例或 AI 生成结论不能替代对问题的分析。研究不要求提供真实交易账户或投入交易资金。

## 三、如何提交

使用[问题模板](templates/question.zh-CN.md)，发送至 [join@singularityx.tech](mailto:join@singularityx.tech?subject=%5BOpen%20Question%5D)，邮件标题为 `[Open Question] <问题名称>`。

提交内容包括：

- **具体问题与价值：** 金融场景、问题范围、现有方法不足及值得研究的原因。
- **已经做过的思考或努力：** 实际考虑过的解释、查阅资料、分析过程、方法尝试或实验，区分已完成工作与后续计划。
- **仍未解决的困难：** 阶段性认识、现有证据、推测和未验证事项，以及需要进一步研究的核心目标。
- **后续研究建议：** 希望挑战者解决什么问题；有初步验证思路、可用资源或约束的，可一并说明。不要求提问者先制定完整验收标准。
- **联系与公开范围：** 姓名或主体名称、有效联系方式、材料来源、允许公开的内容及署名方式。

问题材料默认通过邮件私密提交。适宜公开且有权披露的内容，也可使用仓库 Issues 的“公开研究提问 / Research question”表单，再以邮件提交 Issue 链接及联系信息。公开 Issue 和附件对外可见，私人联系信息、收款资料及保密材料不得放入其中。

代码不是提问的必交材料。如附探索代码，须私密提供责任人真实姓名、有效联系方式及本人 GitHub 个人主页完整链接，代码仓库链接另列。此类附件仅作为前期探索依据，不作为本阶段解答成果奖励申请。

## 四、评审、采纳与奖金

平台结合问题描述、前期思考或探索及未解困难，判断问题是否具有研究价值、是否适合转化为公开挑战。

**提问奖金根据题目本身的研究意义、应用价值、重要程度、影响范围及公开挑战价值综合评定，不根据解题进度或成果完成度分档。** 前期思考或探索用于说明问题依据和未解困难，是提交要求；不以投入时长、代码数量、实验数量或已完成结果的多少确定奖金。

| 提问奖金（人民币税前） | 题目价值评定依据 |
|---|---|
| 2,000 元 | 问题具有明确的金融研究或应用价值，针对具体场景中的实际不足，适合形成边界清晰的公开挑战 |
| 5,000 元 | 问题涉及具有代表性或普遍性的关键瓶颈，对研究方法、系统能力或实际应用具有较大改进价值 |
| 10,000 元 | 问题具有突出的研究意义或应用价值，涉及重要基础性、共性或前沿难题，能够推动相关研究与方法创新 |

平台拟采纳时，与提出者确认问题内容、奖金档位、贡献人、署名及公开范围，并发出书面采纳通知。**正式采纳通知确认提问奖励；收件、补充要求、初评意见或自行创建 Issue 不构成采纳。**

采纳后向提出者支付已确认奖金，并将问题转化为公开挑战。无人解答、解答失败、挑战发布安排调整或问题暂未解决，不影响已经成立的提问奖励。平台实际将提交的问题发布为正式挑战的，不得以遗漏采纳通知为由免除已成立的奖励责任。

同一问题首次按一档计奖，重复发送相同内容不重复支付。相似问题根据具体研究目标、独立思考及新增探索判断，不能仅因标题相近否定贡献。共同形成的问题，在采纳前确认主要贡献人及分配比例；改写、拆分或合并题面不应遗漏实际贡献人。

未获采纳的问题可继续补充研究思考或探索材料，也可提交其他未解决的问题，不设统一提交次数限制。只有新的实质性问题贡献才可另行评审，同一内容不因更换表述重复计奖。

## 五、反馈、支付与挑战发布

工作日按中国大陆法定工作日计算，自对应事项后的下一工作日起算。材料齐全以实际收到所需材料为准，不以延迟确认推迟起算。

| 环节 | 期限与反馈 |
|---|---|
| 收件与完整性检查 | 确认收件并检查材料完整性，集中告知可识别的缺项 |
| 问题初评 | 材料齐全后 5 个工作日内反馈拟采纳意见、需补充事项或未采纳理由 |
| 正式采纳确认 | 采纳条件满足且问题内容、奖金及公开授权确认齐全后发出书面通知 |
| 奖金支付 | 正式采纳并完成必要的收款及税务信息核验后办理，具体支付安排通过邮件通知，并说明依法扣缴情况 |
| 转为公开挑战 | 正式采纳后发布挑战页面或公告，明确任务编号、挑战目标、解答条件及提交入口 |
| 异议复核 | 材料齐全后 3 个工作日内反馈；复杂事项说明已核查内容及后续处理安排 |

需要补充材料或协商公开范围的，应明确待办事项，原则上每 5 个工作日反馈进展。因问题复杂或需要进一步核验而延长评审或复核期限的，应在原期限届满前说明原因及下一反馈节点。文字澄清不重新启动全部评审期限；实质性补充确需重新评估的，仅对受影响部分重新计时并说明原因。出现支付或发布障碍的，应告知原因和后续处理安排，不取消已确认的提问奖金。

采纳后的问题由零界演化整理为 `SX-OR-` 公开挑战，保留提出者的实际贡献记录，并在[发布记录](STATUS.zh-CN.md)提供入口。提出者无需支付设奖费用，也不负责保证后续有人解答。

**本阶段开放的是问题征集。由采纳问题形成的挑战，解答征集须通过该挑战的正式公告另行开放。** 具体题面将明确解答目标、交付材料、验收标准、奖金、名额、预算、评审与支付安排，以及成果授权条件。本页仅公布提问奖金，不预先开放解答、改进、验证或专项奖励。提出者日后如参与解答，也须遵守该挑战的独立公告。

## 六、公开范围与材料权益

平台仅在必要范围内为问题评审、复核、采纳记录和必要留存查看材料。提问奖励对应获采纳的问题贡献及约定的题面公开许可，不自动转让全部材料的知识产权，也不自动授予探索代码、数据或完整报告的商业使用权。

公开的问题内容、摘要、附件与署名方式应在采纳前确认。后续挑战的整理应保留问题来源与贡献记录，不扩大已经确认的公开范围。完整代码、报告或受限数据的使用另行明确，第三方及开源材料遵守原有许可。

姓名、联系方式及付款资料不默认公开。不得提交密钥、账户凭证、内幕信息、客户资料或无权披露的数据；未经授权，不向第三方模型或其他参与者提供未公开材料。个人信息处理按[隐私政策](../docs/privacy-policy.zh-CN.md)执行。

## 七、持续征集与复核

问题征集长期开放，单个问题是否采纳不影响其他提案。规则或奖金调整提前 3 个工作日公示范围及相对生效期限；已采纳问题按已确认金额结算，不追溯减奖、增加义务或扩大授权。暂停受理时应说明范围及既有提交的处理安排。

参与者可通过 `join@singularityx.tech` 对问题认定、署名、奖金或公开范围提出异议，注明提交标识、具体事项及依据。建议收到处理意见后 5 个工作日内提出，该建议不限制依法享有的权利。原决定人不得单独作出最终复核结论；善意异议不得作为扣减已确认奖金的理由。

如实说明的失败尝试可以作为问题探索依据，不因没有取得成功而认定为失职。伪造思考或实验记录、抄袭、冒领贡献等事项，应核实事实并听取说明后按相关规则处理。

本规则适用于本问题征集计划。其他事项适用[平台用户协议](../docs/user-agreement-challenge-rules-and-legal-statement.zh-CN.md)与[法律及合规声明](../docs/legal-notice-and-compliance.zh-CN.md)中未被本专项规则调整的内容。

**本计划及相关公告的所有解释权归零界演化所有。** 解释应遵循法律法规、公平和诚信原则，不得变更已成立的奖励承诺或排除参与者依法享有的权利。

# 金融研究问题提交模板

[English](question.md) ｜ [问题征集规则](../README.zh-CN.md)

**本模板仅用于提出经过思考或探索、仍未解决的问题，不用于提交已经解决的问题或完整解决方案。** 填写后发送至 `join@singularityx.tech`，标题为 `[Open Question] <问题名称>`。

- 如附探索代码：责任人真实姓名、有效联系方式及本人 GitHub 个人主页完整链接：

私人联系信息仅通过邮件提供，不复制到公开 Issue。代码不是必交材料；如提交，个人 GitHub 主页与代码仓库链接分别列明。

## 已经做过哪些思考或努力

至少具体说明一项已进行的思考或探索，不要求已有代码、实验或成功结果。

- 考虑过哪些解释、逻辑或方法，为什么：
- 查阅、分析过哪些资料或案例（如有）：
- 尝试过哪些方法、实践或实验，条件与结果如何（如有）：
- 得到了哪些阶段性认识，哪些尝试无效，为什么仍未解决：
- 可提供的推理记录、资料来源、分析笔记或实验附件（如有）：
- 使用 AI 或 Agent 的方式及本人核对情况（如有）：

实际完成的思考或尝试与未来计划应分开说明；不得将计划、AI 生成内容或他人工作表述为本人已完成的研究。

## 剩余困难与挑战建议

- 现有认识或证据能够说明什么：
- 哪些仍是推测、证据不足或尚未验证：
- 希望外部挑战者进一步解决什么：
- 初步验证思路、可用资源或限制（如有）：

不要求先制定完整验收标准。如已有部分成果，应说明其与未解决问题的关系；完整解决方案不属于本次问题征集。
